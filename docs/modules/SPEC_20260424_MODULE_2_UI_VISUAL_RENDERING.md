## 模块二：UI 渲染与视觉物理学规范 (UI & Visual Rendering)
在渲染或绘制 `.krys` 图像时，前端组件必须严格遵循**“六晶面法则” (The Hex-Facet Rule)**的几何物理映射，确保“人类审美”与“AI机器读取”的双向高保真。

### 2.1 三层六面空间布局法则 (The Sigil Anatomy)
所有输出的 Krystal 图像在 Canvas/SVG 渲染时需分为三个绝对图层：

1.  **第一层：晶核 (The Core) - 人类审美层**
    *   **位置与尺寸**：图像正中心，严格占据 40% 的画幅区域。
    *   **内容**：承载 AI 技能的视觉隐喻（Sigil），例如黑曜石、电路发光体等。该层纯为人类提供情绪价值，前端无需对大模型做精确读取适配。
2.  **第二层：带隙 (The Band Gap) - 状态指示层**
    *   **位置与尺寸**：环绕“晶核”边缘的 1-2px 光晕层。
    *   **前端色彩规范（强制 sRGB 绝对色值，确保抗压缩不失真）**：
        *   🟢 **安全 (纯文本/本地执行)**：孔雀石绿 `#0BDA51`
        *   🟡 **警告 (含外部 API/包裹体)**：琥珀金 `#FFBF00`
        *   🔴 **高危 (高危权限/恶意拦截)**：辰砂红 `#E30022`
        *   🔵 **工具 (含外部工具调用)**：标准蓝（视 UI 补充）
        *   🟣 **多模态 (创意型任务)**：幻影紫（视 UI 补充）
3.  **第三层：六晶面 (The 6 Facets) - 大模型执行层**
    *   **视觉形态**：分布在图像外围的 6 个棱边/边框区域，必须采用“数据金丝工艺 (Data Filigree)”，将高密度编码伪装成复古拉丝花纹或魔法阵边缘。

### 2.2 六晶面精确数据映射与方向规范
前端在生成（渲染）或解析区域时，**必须**遵循以下顺时针方位与内容映射逻辑：
*   **👑 顶棱 (Crown Facet)**：占信息量 10%。古典/赛博字体，包含晶核名称、版本号及重要唤醒词（如 `"Initialize KIP Protocol"`）。
*   **↗️ 右上棱 (Input Facet)**：占信息量 15%。定义输入切面，指示要求用户提供的输入格式。
*   **↘️ 右下棱 (Logic Facet)**：占信息量 40%。核心逻辑层（System Prompt）。必须采用高密度的长条纹金丝编码（微型 Data Matrix 变体）。
*   **👢 底棱 (Output Facet)**：占信息量 15%。输出切面的格式约定与语气模板。
*   **↙️ 左下棱 (Inclusion Facet)**：占信息量 10%。包裹体位置，放置外部知识索引、微型二维码或 Hash 指针。
*   **↖️ 左上棱 (Correction Facet)**：占信息量 10%。晶格校正层，用于放置容错冗余代码和防大模型幻觉的机制。

### 2.3 图像物理属性与容错锚点 (Canvas 制图约束)
为了防止多模型在切图 (Tiling) 时产生视觉幻觉，前端的生成与渲染器必须遵守以下底层约束：
*   **分辨率推荐**：强制为 `1024x1024` 或 `1536x1536` 的正方形比例，确保六边形对称。
*   **象限锁定锚点 (Quadrant Lock Anchors)**：
    *   **渲染规则**：在六晶面的每个交界处（即四个角及连线交汇处），必须嵌入一个 **2x2 像素的固定基准色块**（如品红 `#FF00FF`）。
    *   **目的**：为大模型提供类似“晶轴 (Crystallographic Axis)”的视觉坐标基准，确保在跨平台和被压缩的环境下，AI 能够通过 RFRL 透镜精准锁定读取范围。
