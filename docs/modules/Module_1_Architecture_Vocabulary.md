## 模块一：全局架构与组件词典 (Architecture & Vocabulary)
作为前端开发 Agent，你必须在变量命名、组件划分与逻辑流转中严格遵循**三位一体 (The Trinity Architecture)**的世界观设定，杜绝使用传统大厂的“应用/App/容器”等词汇。

### 1.1 三位一体核心层级
*   **骨架层 (The Skeleton) - 技术协议与载体**
    *   **底层协议：KIP (Krystallized Intent Protocol，晶化意图协议)**。这是一套定义如何将AI提示词、逻辑隐写入图像的通用标准。
    *   **载体实体：Krystal 载体**。承载协议的具体文件表现形式。
    *   **文件后缀：`.krys` (Krystal File)**。AI 时代的可执行视觉文件格式。
*   **灵魂与体验层 (The Soul & Experience) - 用户感知与美学**
    *   **前端应用：Crystal (晶体工坊 / Crystal Studio)**。普通用户进行无代码交互的唯一前端界面。
    *   **核心功能动作：秘符铸造 (Sigil Forging)**。将底层逻辑代码渲染成高美感视觉图像的生成过程。
    *   **美学设计语言：Sigil (秘符美学)**。结合古典珠宝几何切割、隐秘镶嵌与赛博霓虹带隙的高密度视觉规范。
*   **工具链层 (The Toolchain) - 编译器与开发者生态**
    *   **技术语言/底层网状结构：Xtal (交叉晶格)**。
    *   **核心引擎：Xtal-Compiler (晶格编译器)**，负责将自然语言转化为 `.krys` 文件的JSON载荷；**Xtal-Validator (晶格校验器)**，负责前端的安全审计与防篡改验证。

### 1.2 前端工程词典与组件映射
*   **Facet (切面)**：组件对外的参数输入口或子功能模块（例如：输入切面、输出切面）。
*   **Inclusion (包裹体)**：指向外部私有知识库、数据库索引或 API 的标识指针。
*   **Refract (折射)**：大模型读取晶体并执行输出的过程（替代“运行/调用”）。
*   **Lattice Mismatch (晶格失配)**：当前端检测到视觉图像（明轨）与底层隐写数据（暗轨）发生哈希不一致，或多模型解析异常时抛出的前端报错状态。
