## 1. 快速上手

Crystal Studio 是一个用于创建、浏览和执行 **Krystal (.krys)** 文件的桌面应用。Krystal 是 AI 能力的可视化封装格式——把你的提示词/需求打包成一个漂亮的图像文件，任何多模态 AI 模型都能读取和执行。

### 1.1 启动应用

```bash
cd crystal-studio
npm run dev
```

浏览器打开 `http://localhost:5773`。

### 1.2 三种使用方式

| 方式 | 适合场景 | 操作步骤 |
| :--- | :------- | :------- |
| **快速导入 ⚡** | 新手、快速创建 | 粘贴文本 → 一键生成 → 下载 .krys |
| **手动铸造** | 精细控制 | 填写表单 → 实时预览 → 下载 |
| **重结晶** | 修改已有晶体 | 在观测站加载 → 点击重结晶 → 修改 → 下载 |

## 2. 铸造台 — Forge

这是创建 Krystal 文件的主要入口。

### 2.1 快速导入（推荐新手使用）

**操作步骤**:

1. **打开铸造台** — 启动后默认进入快速导入模式

2. **粘贴你的需求或文档**
   ```
   ┌─────────────────────────────────────┐
   │ 你是一个代码审查专家，专门审查       │
   │ TypeScript 项目。每次审查时，        │
   │ 你需要检查：                         │
   │ 1. 类型安全                          │
   │ 2. 边界条件                          │
   │ 3. 代码风格                          │
   │ 输出格式为 Markdown 报告。           │
   └─────────────────────────────────────┘
   ```

3. **或上传文档文件** — 支持 .txt / .md / .json / .csv / .py 等格式

4. **预览自动解析结果** — 系统自动检测：
   - 晶体名称 ← 第一行或文件名
   - 安全等级 ← 关键词（API Key→Caution, 删除→Restricted）
   - 联网需求 ← 自动识别 URL
   - 输入/输出格式 ← JSON/Markdown/CSV 等

5. **点击「⚡ 一键生成晶体结构」**

6. **点击「💎 确认结晶」** — 下载 `.krys` 文件

**示例**:

```
你粘贴的内容：
  "你是一个翻译助手，把中文翻译成英文。
   输出 JSON 格式：{"original": "", "translated": ""}"

系统自动解析：
  ├─ 名称: 你是一个翻译助手
  ├─ 安全: SAFE (纯文本)
  ├─ 等级: Tier 1 (完全离线)
  ├─ 格式: JSON
  └─ 唤醒词: Initialize 翻译助手
```

### 2.2 高级设置（可选）

点击「▼ 高级设置」展开完整表单，可以手动微调：

| 区块 | 可调整参数 |
| :--- | :--------- |
| [CROWN] 晶核身份 | 名称、版本、作者、晶级、唤醒词 |
| [BAND GAP] 带隙 | Safe / Caution / Restricted / Tool / Multimodal |
| [LOGIC] 核心逻辑 | System Prompt（晶体执行的灵魂） |
| [INPUT] 输入切面 | 输入格式、说明 |
| [OUTPUT] 输出切面 | 输出格式、语气模板 |
| [INCLUSION] 包裹体 | API 端点、知识库引用 |
| [CORRECTION] 容错冗余 | 离线降级提示词、冗余纠错代码 |

### 2.3 晶核 Sigil 图像（可选）

上传一张图片作为晶核视觉符号。不上传也没关系，系统会自动生成一个渐变晶核。

## 3. 观测站 — Observe

已有 `.krys` 文件的浏览和执行工具。

### 3.1 加载 Krystal

**方法 1: 拖放**
- 将 `.krys` 文件直接拖入观测站区域

**方法 2: 文件选择器**
- 点击「选择文件」按钮

### 3.2 查看晶体信息

加载成功后，可以看到：
- 晶体名称、版本、作者
- 安全等级（Band Gap 颜色指示）
- 晶级（Tier 1/2/3）
- KIP 协议版本

### 3.3 色散 Dispersion — 查看六晶面

点击各切面区块展开查看：
- **[CROWN]** 名称和唤醒词
- **[INPUT]** 期望的输入格式
- **[LOGIC]** 完整 System Prompt
- **[OUTPUT]** 输出格式要求
- **[INCLUSION]** 外部 API 端点
- **[CORRECTION]** 容错/降级策略

### 3.4 折射 Refract — 执行 Krystal

1. 配置 AI 模型
2. 输入你的问题/数据
3. 点击「折射」
4. 查看 AI 输出结果

**安全门控**: 如果 Krystal 标记为 Caution 或 Restricted，系统会弹出确认提示。

### 3.5 明轨降级（图片压缩后）

如果 `.krys` 文件经过社交媒体压缩导致暗轨数据丢失：

1. 观测站会自动显示「明轨 OCR 解析」面板
2. 将压缩后的图片中的文字粘贴到文本框中
3. 系统会尝试从文本锚点（[CROWN]、[LOGIC] 等）恢复数据

### 3.6 重结晶

点击「重结晶」按钮，跳转到铸造台并预填当前晶体的参数，方便迭代更新。

## 4. 晶簇工坊 — Cluster

将多个 Krystal 组合成一个多智能体工作流。

### 4.1 创建晶簇

1. **拖入**或**选择**多个 .krys 文件
2. 为晶簇命名
3. **连线**：选择一个源节点 → 点击目标节点 → 输入标签
4. 连线表示数据流向：上游的输出 = 下游的输入

### 4.2 执行晶簇

1. 配置 AI 模型（所有节点共享同一配置）
2. 为第一个节点输入初始数据
3. 点击「执行晶簇」
4. 系统按拓扑顺序执行每个节点，自动传递上游输出

### 4.3 结果查看

每个节点的执行状态以卡片形式展示：
- ⏳ `pending` — 等待执行
- 🔄 `running` — 执行中
- ✅ `done` — 执行完成，有输出
- ❌ `error` — 执行失败

## 5. 安全机制

### 5.1 Band Gap 安全等级

| 等级 | 颜色 | 触发条件 | 前端行为 |
| :--- | :--- | :------- | :------- |
| 🟢 Safe | 绿色 | 纯文本/本地执行 | 无提示，直接执行 |
| 🟡 Caution | 琥珀色 | 包含 API 调用/外部网络 | 弹出确认框「此晶体请求网络访问，是否继续？」 |
| 🔴 Restricted | 红色 | 高危权限/恶意拦截 | 强制阻断，必须确认才能继续 |
| 🔵 Tool | 蓝色 | 工具调用 | 正常执行 |
| 🟣 Multimodal | 紫色 | 多模态任务 | 正常执行 |

### 5.2 离线降级

- 浏览器检测到离线时，状态条会显示「离线」
- Tier 3 晶体在离线时会自动使用 Correction Facet 中的降级提示词
- 应用不会白屏或崩溃

### 5.3 晶格校验

加载 Krystal 时，系统会自动：
1. 计算 SHA-256(像素 + JSON + 带隙色)
2. 与文件中存储的指纹对比
3. 不匹配时触发「晶格失配 (MISMATCH)」警报

## 6. 常见问题

### Q: 快速导入生成的晶体不够准确怎么办？

A: 导入后点击「▼ 高级设置」，可以手动调整 System Prompt、Band Gap 等级等参数。

### Q: 可以用什么 AI 模型？

A: 支持 OpenAI (GPT-4/3.5)、Gemini (Pro/Flash) 以及符合 OpenAI 格式的兼容 API。在观测站左侧面板配置 API Key。

### Q: .krys 文件可以分享吗？

A: 可以。.krys 文件本质是 PNG 图像，可以在社交媒体、聊天软件中分享。接收方用 Crystal Studio 的观测站打开即可。

### Q: 为什么我拖入的 .krys 文件提示晶格失配？

A: 这意味着文件的视觉数据和暗轨数据指纹不一致——文件可能在传输中损坏或被篡改。建议重新获取原始文件。

### Q: 为什么我的文件在明轨 OCR 后只能恢复部分数据？

A: 这是预期的。明轨是第二优先级降级方案，目标恢复 ≥70% 核心逻辑。完整数据需要原始 .krys 文件的暗轨。

### Q: 如何更新一个已有的 Krystal？

A: 在观测站加载 → 点击「重结晶」→ 在铸造台修改参数 → 重新下载。
